Join us for a hands-on workshop where we'll unpack the inner workings of software agents and guide you through the process of building your own coding agent, akin to Claude Code or GitHub Copilot. With Microsoft's new Agent Framework, you'll learn about tools, memory usage, and the skills needed to create effective agents, moving beyond the basics of RAG chatbots.

We'll kick off the day with an introductory presentation, laying the groundwork for what makes a good agent. As we move into lab sessions, you'll work collaboratively to implement the core components of your coding agent, followed by stretch goals in the afternoon to challenge your newfound skills. Throughout the day, you'll have direct access to two experts ready to assist you with any questions.

**Prerequisites:** Basic C# programming skills and a laptop with Visual Studio Code or the ability to install software. No prior experience in agent development is required.

**What you'll walk away with:** A fully functional coding agent that serves as a foundation for any future agent development you pursue.
